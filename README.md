Network-Tool-Framework is a comprehensive Python-based tool designed to perform full network assessments, enumeration, and report generation. This tool provides functionalities to unlock various network details and generate detailed reports in PDF format with visual representations.

## Features

- **Network Enumeration**: Discover network devices, open ports, services, and vulnerabilities.
- **Data Processing**: Extract key metrics from network scan results.
- **Visual Reports**: Generate visual reports including charts and graphs for better analysis.
- **Security Scoring**: Calculate security scores based on vulnerabilities and open ports.
- **Regression Analysis**: Perform regression analysis to understand the impact of different factors on network security.
